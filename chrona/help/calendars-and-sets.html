Calendars and Calendar Sets

The leading slash, and switching context in one tap

Your real calendars

Chrona reads and writes the calendars already on your device — iCloud, Google, Exchange, work accounts, subscribed calendars. It is not a separate silo. Invitations, shared calendars, and alerts keep behaving exactly as they did, and anything you create in Chrona shows up in every other calendar app you use.

Choosing a calendar as you type

/work Review PRs tomorrow at 9
/personal Dentist friday at 3pm

A leading slash picks the calendar to save to. The name has to match one of your actual calendars; if it does not, Chrona leaves the text in the title rather than silently filing the event somewhere you did not intend.

Calendar Sets

A Calendar Set is a named group of calendars — “Work”, “Family”, “Just me” — that you switch between in one tap, instead of toggling a checklist of twelve calendars every time your context changes.

Sets remember calendars by identity, not by position, so adding or removing a calendar later never scrambles a set. If a set ends up referring only to calendars that no longer exist, Chrona shows you everything rather than showing you an empty screen — a blank calendar is never the helpful answer.
