Troubleshooting

It made a task instead of an event, sync is behind, the time is off

It created a task and I wanted an event

The sentence had no clock time. Lunch friday is a task due Friday; Lunch friday at noon is an event. See Getting started.

It created an event and I wanted a task

Start with todo, or add a #tag or >Project. Any of the three forces a task even with a time on it.

The time is twelve hours off

A bare hour from 1 to 7 is read as PM — “at 6” means 6 PM. Write at 6am when you mean the morning.

Part of my sentence ended up in the title

That is Chrona telling you it did not recognise that phrase. Nothing is ever silently discarded: text the parser cannot place stays in the title where you can see it. Check the wording against the syntax reference — the usual culprits are a time range without an am/pm (3-4 instead of 3-4pm) and a /calendar name that does not match a calendar you actually have.

My event is not in my other calendar app

Check which calendar it was saved to. If Chrona did not have permission to a particular calendar account, or the event went to a local calendar rather than your iCloud or Google one, it will not appear elsewhere. Open the event and look at its calendar; use a leading /name to direct future ones.

Tasks are not syncing between my devices

Task sync runs over your own iCloud account. Every device needs to be signed into the same Apple ID with iCloud enabled for Chrona. Sync is a background process and can take a minute; if a device is still behind, confirm it has a network connection and relaunch the app.

Events are not affected by this — they live in your device calendars and sync through whichever account owns them (iCloud, Google, Exchange).

Weather is not showing

The forecast needs approximate location permission, and is a Pro feature. Enable it in Settings → Privacy & Security → Location Services → Chrona.
